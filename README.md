Sono un **ingegnere software** appassionato di **intelligenza artificiale**. Mi piace trasformare idee concrete in app che semplificano la vita di tutti i giorni, dal piatto che mangiamo al cibo che rischiamo di sprecare.

Oggi porto avanti due progetti personali: **Kindplate** e **Dispenzy**.

## 🚀 I miei progetti

### 🍽️ [Kindplate](https://kindplate.it)
**Un'app per la gestione della nutrizione, senza giudizio e senza la paura della dieta.**

Il nome unisce *kind* (gentile) e *plate* (piatto): un piatto gentile. Kindplate accompagna il rapporto tra nutrizionista e paziente, con un approccio all'alimentazione più sereno e meno ansiogeno.

- 🌐 Sito: [kindplate.it](https://kindplate.it)
- 🛠️ Stack: React Native · Firebase (Cloud Functions, Security Rules)

### 🥫 [Dispenzy](https://dispenzy.it)
**L'app per tenere sotto controllo le scadenze di dispensa, frigo e freezer, e dire basta allo spreco alimentare.**

- ⏰ **Gestione delle scadenze** degli alimenti in dispensa, frigo e freezer
- 🔔 **Notifiche** prima che il cibo scada
- 🤖 **Ricette antispreco** suggerite dall'AI tramite prompt, partendo da ciò che hai già in casa
- 👨‍👩‍👧 **Dispensa condivisa** con familiari o coinquilini
- ...e altro in arrivo
- 🌐 Sito: [dispenzy.it](https://dispenzy.it)
- 🛠️ Stack: React Native · Firebase (Cloud Functions, Security Rules)

> Entrambe le app sono costruite in modalità **serverless**: React Native sul client e Firebase con Functions e Rules, senza un backend dedicato.
